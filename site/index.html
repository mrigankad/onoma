From messy files to search that explains itself

Four steps. Nothing goes live in the vocabulary until a person says yes.

1

Import

CSV, Excel or JSON. Schema Scout finds the title, vocabulary and number columns, and skips personal data.

2

Agents suggest

Alias Miner spots “k8s”, “ACL tear”, “HCl 35%”. Every suggestion carries its evidence.

3

People decide

Same thing, different, or only in one dataset. One key each, and every decision is audited.

4

Search, explained

In the console, over REST, or from any AI agent through MCP. Every hit says why it matched.

Running in two minutes

Python 3.12+ and uv for the engine, Node 20+ for the console. Or docker compose up.

# engine
$ git clone https://github.com/mrigankad/onoma
$ cd onoma/engine && uv venv && uv pip install -e .
$ .venv/bin/onoma demo
$ .venv/bin/onoma search "heart attack over 60"
$ .venv/bin/onoma serve
# any MCP client
{ "mcpServers": { "onoma": {
    "command": "onoma",
    "args": ["--db", "onoma.db", "mcp"]
} } }
